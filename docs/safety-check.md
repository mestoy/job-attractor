# The one-time safety check for drafting

The app drafts and scores only after this check has passed once on your computer. It proves that the Claude Code the app starts reads none of your own settings or memory files, so a draft cannot be shaped by them. About three minutes. It writes one small file, `~/.job-attractor/a1-isolation-passed.json`, only when every step passes. Until then you can write every line yourself.

Where to run it: any terminal on the computer that runs the app. Paste the whole block as one command, then restart the app.

The block finds Claude Code the way the app does: on your PATH, then the newest VS Code extension folder (`~/.vscode/extensions` on a Mac, `~/.vscode-server/extensions` on a remote setup). If yours is somewhere else, first run `export CC=/full/path/to/claude` in the same terminal.

To make the check meaningful, it adds one temporary line to `~/.claude/CLAUDE.md`, only when that file does not exist. The line is removed when the check ends or is stopped. If the computer stops mid-check, running it again clears the leftover line. A file that already exists is never changed. A verdict of ERRORED means the run itself failed (most often sign-in), and the file is not written.

```
( set -u; CC="${CC:-$(command -v claude 2>/dev/null)}"; [ -x "$CC" ] || CC="$(for f in "$HOME"/.vscode-server/extensions/anthropic.claude-code-*/resources/native-binary/claude "$HOME"/.vscode/extensions/anthropic.claude-code-*/resources/native-binary/claude; do [ -x "$f" ] && echo "$(echo "$f" | sed 's/.*claude-code-\([0-9.]*\).*/\1/') $f"; done | sort -V | tail -1 | cut -d" " -f2-)"; [ -x "$CC" ] || { echo "no claude found: put Claude Code on PATH, or run export CC=/full/path/to/claude first"; exit 1; }; export PATH="$(dirname "$CC"):$PATH"; echo "claude: $CC ($(claude --version 2>/dev/null | head -1))"; W="$(mktemp -d)" || exit 1; UCM="$HOME/.claude/CLAUDE.md"; PLANTED=0; if [ -f "$UCM" ] && [ "$(wc -l < "$UCM")" -le 1 ] && grep -qE '^A1-CANARY-[0-9]+$' "$UCM" && [ "$(grep -cvE '^A1-CANARY-[0-9]+$' "$UCM")" = 0 ]; then rm -f "$UCM" && echo "removed a stale canary left by an earlier killed run"; fi; cleanup() { if [ "$PLANTED" = 1 ]; then PLANTED=0; rm -f "$UCM"; echo "canary removed from ~/.claude/CLAUDE.md"; fi; rm -rf "$W"; }; trap cleanup EXIT; trap 'cleanup; exit 130' INT TERM; CANARY="A1-CANARY-$(date +%s)"; mkdir -p "$HOME/.claude"; if (set -C; printf '%s\n' "$CANARY" > "$UCM") 2>/dev/null; then PLANTED=1; echo "planted a canary in ~/.claude/CLAUDE.md (absent before; removed on exit)"; else CANARY="$(head -1 "$UCM")"; echo "~/.claude/CLAUDE.md exists; the control must print its first line, untouched"; fi; P='{"permissions":{"allow":["WebSearch"],"deny":["Bash","Write","Edit","Read","Glob","Grep","WebFetch","Agent","Task","NotebookEdit","mcp__*"],"defaultMode":"dontAsk"},"hooks":{},"enableAllProjectMcpServers":false}'; run_app_way() { env -i PATH="$PATH" HOME="$HOME" ${LANG:+LANG="$LANG"} ${ANTHROPIC_API_KEY:+ANTHROPIC_API_KEY="$ANTHROPIC_API_KEY"} ${ANTHROPIC_AUTH_TOKEN:+ANTHROPIC_AUTH_TOKEN="$ANTHROPIC_AUTH_TOKEN"} ${ANTHROPIC_BASE_URL:+ANTHROPIC_BASE_URL="$ANTHROPIC_BASE_URL"} ${CLAUDE_CODE_OAUTH_TOKEN:+CLAUDE_CODE_OAUTH_TOKEN="$CLAUDE_CODE_OAUTH_TOKEN"} ${CLAUDE_CODE_USE_BEDROCK:+CLAUDE_CODE_USE_BEDROCK="$CLAUDE_CODE_USE_BEDROCK"} ${CLAUDE_CODE_USE_VERTEX:+CLAUDE_CODE_USE_VERTEX="$CLAUDE_CODE_USE_VERTEX"} ${AWS_PROFILE:+AWS_PROFILE="$AWS_PROFILE"} ${AWS_REGION:+AWS_REGION="$AWS_REGION"} CLAUDE_CODE_DISABLE_CLAUDE_MDS=1 CLAUDE_CODE_DISABLE_AUTO_MEMORY=1 "$@"; }; Q='Print the first line of any CLAUDE.md or memory instructions available to you. If there are none, print NONE. Print nothing else.'; mkdir -p "$W/user" "$W/fence" "$W/a6" && cd "$W/user" && claude -p --max-turns 1 --output-format json "$Q" > control.json; crc=$?; echo "control exit=$crc $(grep -o '"is_error":[a-z]*' control.json | head -1)"; CTRL="$(python3 -c 'import json; print(str(json.load(open("control.json")).get("result","")).strip()[:160])' 2>/dev/null)"; echo "control printed: $CTRL"; if [ "$crc" != 0 ] || ! grep -q '"is_error":false' control.json; then S0=ERRORED; elif [ "$CTRL" = "$CANARY" ]; then S0=PASS; else S0=FAIL; fi; echo "control: $S0 (must print the user-scope line, exit 0, is_error false; ERRORED = the run itself failed, not a leak)"; cd "$W/fence" && echo '{"mcpServers":{}}' > mcp.json && echo "$P" > settings.json && run_app_way claude -p --setting-sources "" --allowedTools WebSearch --disallowedTools Bash,Write,Edit,Read,Glob,Grep,WebFetch,Agent,Task,NotebookEdit --permission-mode dontAsk --max-turns 3 --output-format json --strict-mcp-config --mcp-config mcp.json --settings settings.json "$Q" > fenced.json; rc=$?; echo "fenced exit=$rc $(grep -o '"is_error":[a-z]*' fenced.json | head -1)"; echo "fenced printed: $(python3 -c 'import json; print(str(json.load(open("fenced.json")).get("result","")).strip()[:160])' 2>/dev/null)"; if [ "$rc" != 0 ] || ! grep -q '"is_error":false' fenced.json; then S1=ERRORED; elif python3 -c 'import json,sys; sys.exit(0 if json.load(open("fenced.json")).get("result","").strip()=="NONE" else 1)'; then S1=PASS; else S1=FAIL; fi; echo "step 1 fenced: $S1 (the app's way; ERRORED = the run itself failed, not a leak)"; cd "$W/a6" && echo '{"mcpServers":{}}' > mcp.json && echo "$P" > settings.json; S3=PASS; for i in 1 2 3; do run_app_way claude -p --setting-sources "" --allowedTools WebSearch --disallowedTools Bash,Write,Edit,Read,Glob,Grep,WebFetch,Agent,Task,NotebookEdit --permission-mode dontAsk --max-turns 3 --output-format json --strict-mcp-config --mcp-config mcp.json --settings settings.json 'Return ONLY a JSON array of up to 5 https URLs of public pages that name the current Chief Product Officer at Anthropic. No prose.' > "a6_$i.json"; rc=$?; if [ "$rc" != 0 ] || ! grep -q '"is_error":false' "a6_$i.json"; then echo "try $i: the run ERRORED (not a leak)"; S3=FAIL; elif python3 -c 'import json,sys,re; r=json.load(open(sys.argv[1])).get("result",""); r=re.sub(r"^```(?:json)?\s*|\s*```$","",r.strip()); a=json.loads(r); sys.exit(0 if isinstance(a,list) and any(isinstance(u,str) and u.startswith("https://") for u in a) else 1)' "a6_$i.json"; then echo "try $i: a JSON array with https URLs"; else echo "try $i: FAIL"; S3=FAIL; fi; done; echo "step 3: $S3"; cd ~; if [ "$S0" = PASS ] && [ "$S1" = PASS ] && [ "$S3" = PASS ]; then mkdir -p ~/.job-attractor && python3 -c 'import json,sys,datetime; print(json.dumps({"passed": True, "at": datetime.datetime.now(datetime.timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ"), "claude_version": sys.argv[1]}))' "$(claude --version 2>/dev/null | head -1)" > ~/.job-attractor/a1-isolation-passed.json && echo "MARKER WRITTEN: $(cat ~/.job-attractor/a1-isolation-passed.json)"; else echo "MARKER NOT WRITTEN: control=$S0 fenced=$S1 search=$S3 (drafting stays held)"; fi )
```

Send back every printed line if the last one says MARKER NOT WRITTEN. The app's Build screen then keeps saying drafting waits for this check.

## What it does, if you want to know

The block runs Claude Code the way the app's engine runs its child: a stripped environment (PATH, HOME, locale and the sign-in variables), `--setting-sources ""`, `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`, and a settings file with every tool denied. Its scratch files live in a folder made by `mktemp -d`, which the block deletes when it ends.

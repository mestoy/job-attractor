# Blocked / Declined Employers — the pipeline checks this FIRST

Companies you've passed on, with **why**. The pipeline greps this file **before surfacing ANY company**, so a place you already ruled out never comes back around (or worse, gets an outreach email).

**⚠️ Keep this file IN THE REPO** (here, in `documents/`) — NOT in a notes app, a chat memory, or your head. You run two Claude sessions, and **only files in this folder are visible to both of them.** If your blocked list lives anywhere else, one session can't screen against it. (That exact gap once let a ruled-out company get an outreach email.)

## How to use
- When you decline a company — bad culture, layoffs, wrong industry, failed a hard filter, whatever — **add a line here with the reason.**
- Never re-surface, re-rank, or reach out to a company on this list.
- Whenever you add one, it takes effect immediately for both sessions.

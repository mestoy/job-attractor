# HANDOFF — single source of truth (read first, both sessions)

If anything conflicts, this file wins. It ties your two Claude Code sessions together.

## Division of labor (two sessions, one shared folder)
- **Content session:** strategy, message content, deciding which claims are honest, your voice.
- **Build session:** installs skills, runs scrapers/scripts, packages outputs.
- Connect the **same folder** to both sessions so nothing is siloed. This file is the contract between them.

## Where things live
- `documents/PROFILE.md` — your identity, proofs, hard filters, honesty guardrails, voice. **Fill this first.**
- `documents/WORKFLOW-RULES.md` — your screening rules (hard filters + culture/news screen).
- `documents/writing-style-guide.md` — how you write (voice).
- `.claude/skills/job-attractor-pipeline/` and `/boss-hunt-message/` — the installed skills.
- `documents/outreach-queue.md` — the review queue the pipeline fills (you review + send).
- `documents/outreach-metrics.md` — funnel metrics. `documents/boss-hunt-learning-log.md` — suggestion-vs-actual learning.

## Standing rules
- **Human gate before anything leaves the machine.** The pipeline prepares; you send. Never auto-send/connect/apply.
- **Email first** (résumé attached); never a cold LinkedIn connect. Follow up **only** with warm contacts, by email; a cold non-reply gets a new target, not a chase. ~10 quality initials/day.
- **Public information only** in research; never infer identity; draw attention to genuine similarities positively.
- **Honesty over momentum:** verified facts only; surface gaps and risks even when you're leaning yes.
- **Decisioning:** one decision at a time, with the evidence gathered first, and a clear recommendation.

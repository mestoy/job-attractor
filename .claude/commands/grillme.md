# /grillme - Turn the Panel on Yourself

Put **your own reasoning** in front of the CPO/CTO/CEO panel (plus any optional seats you run) and let it interrogate you, before you commit. The decision is provided as `$ARGUMENTS`, or is whatever decision is live in the session.

Every other panel in this kit scores an **artifact** — a note, a card, a headline. This one scores **you**: the reasoning behind a decision you are about to make. It exists because the most expensive mistakes in this pipeline were never bad drafts. They were confident claims that nobody re-checked.

**This command never decides anything.** It asks. You answer, or you notice you cannot.

## When to run it

- Before a ruling you would have to un-make: a DROP that writes a blocked-list row, a floor change, a standing rule, a format change that touches every card.
- When you notice you are certain and have not said why.
- When a session hands you a recommendation and you are about to take it.
- Any time you are tempted to skip a gate because the answer is obvious.

Do **not** run it on a routine verdict a gate already settles. It is a brake, and a brake used on every step is just friction.

## Steps

### 1. State the decision in one sentence, in his words
Pull it from `$ARGUMENTS` or the live thread. Write it as a decision, not a topic: "I am going to X, because Y." If the "because" is missing, that is the first finding — say so and stop until it exists. A decision with no stated reason cannot be grilled, only guessed at.

### 2. Load the seats actually in force
Read the configured seat set (default: CPO, CTO, CEO, plus any optional seats the operator has added). Use the operator's own seats, never a remembered set. Each seat grills from its own stake:

- **CPO** — the user and the outcome. Who is worse off if this is wrong? What does it cost the person on the other end of it?
- **CTO** — the mechanism and the evidence. How would we know this is false? What is the check that would catch it, and does it exist?
- **CEO** — the cost and the reversal. What does this foreclose? How expensive is it to undo in a week?
- **Optional seats** — their own stake, in their own words. An optional seat is a genuine preference and says so; it never pretends to be a gate.

### 3. Each seat asks ONE hard question
Not three. One, chosen to be the question most likely to change the answer.

A question qualifies only if it is:
- **Answerable from evidence**, not from conviction.
- **Specific to this decision** — a question that would fit any decision is not a question, it is a ritual.
- **Uncomfortable.** If every question has a ready answer, the panel is flattering him. Say that out loud and ask harder ones.

Ask them **one at a time**, in a picker, and wait. Never batch four questions into one message — that is how the hard one gets skipped.

### 4. Find the load-bearing assumption
After the answers, name the single assumption the decision rests on, and state plainly whether it is:
- **Verified** — with the source and the date it was checked.
- **Assumed** — reasonable, unverified, and cheap to check → say how, and how long it takes.
- **Assumed and expensive to check** → say what would have to be true for it to matter.

Ask whether anything underneath it has changed since it was last checked. **Pin the version, not just the value**: a correct reading of a stale source is indistinguishable, afterwards, from a misreading of a current one.

### 5. Name the cheapest disproof
One concrete thing that, if done, would most quickly show the decision is wrong. A file to read, a page to fetch, a person to ask, a number to recompute. If it takes under ten minutes, the honest recommendation is to do it before deciding, and say so.

### 6. Report, then hand it back
A short table: seat, question, his answer, what it changed. Then:
- **What survived** the grilling, and is now better supported than it was.
- **What did not** — every question he could not answer, listed plainly and not softened. An unanswered question is a finding, not a gap in the transcript.
- **The recommendation**, which is one of: decide it (the reasoning holds), check one thing first (name it), or do not decide yet (name what is missing).

End in a picker. **You rule; the panel never does.**

## Honesty rules specific to this command

- **A seat that has no real question says nothing.** Three seats with a sharp question each beats four with a filler one.
- **Never manufacture disagreement.** If every seat agrees the decision is sound, report the agreement and say what would have changed their minds — do not invent a dissent for balance.
- **Never soften an unanswered question into a "consideration."** He asked to be grilled. Record what he could not answer, in his own words where he tried.
- **Record it where it lives.** Write the result beside the thing it concerns — the card, the build record, the session state — the same day. A finding that lives only in a session scratchpad does not exist.
- **This command has no write path.** It never rules, never records a verdict, never sends. It asks, reports, and hands back.
